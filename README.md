# Oncourse course language review

Visual, screen-by-screen terminology recommendations for CPA, CFA, LSAT, BAR, MCAT and NCLEX under ONC2-7197.

- `index.html` — CPA review
- `cfa.html` — CFA review
- `lsat.html` — LSAT review
- `bar.html` — BAR review (NextGen bar exam)
- `mcat.html` — MCAT review
- `nclex.html` — NCLEX-RN review

`shared.js` holds the screens every course shares, the "Where in the app" paths and the "Labels to remove or rename" (PYQ, Topper…) inventory.

The published GitHub Pages URL is updated whenever changes are pushed to `main`.
